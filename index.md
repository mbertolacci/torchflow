# torchflow

Normalizing flows in R using the [torch](https://torch.mlverse.org/)
package.

You can install this package from source using the `devtools` package:

`{r} devtools::install_github('mbertolacci/torchflow')`

Go read the vignette on the package website to learn more:
[torchflow](https://mbertolacci.github.io/torchflow/).
